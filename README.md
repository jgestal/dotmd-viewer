# DotMD Viewer

A simple, cross-platform Markdown viewer — with optional editing — for macOS, Windows and Linux.
The little sibling of [DotMD](https://github.com/jgestal/dotmd).

> 🚧 Work in progress. See [PLAN.md](PLAN.md).
